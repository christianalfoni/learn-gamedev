# The Gamedev Sketchbook

A practice log for 26 small gamedev sketches across **Godot 4**, **Aseprite**, **Audacity** and
**FL Studio**, plus per-tool setup notes and links to the people worth learning from.

Live: **https://christianalfoni.github.io/learn-gamedev/**

Each sketch is 15–90 minutes and self-contained. Filter by tool, by session length, or by whether
you've done it yet. Click a cell in the palette grid to jump to a sketch. Logging a session bumps a
rep counter rather than crossing anything off — re-doing a sketch weeks later is the point.

## Files

- `index.html` — the whole thing. One self-contained file: no build, no dependencies, no server.

## Progress

Progress lives in the browser's `localStorage`, so it's per-machine and per-browser. Use the
**Export** button for a JSON backup and **Import** to restore it elsewhere.

## Editing

Open `index.html` and edit the `SKETCHES`, `MODULES`, `BENCH` or `PRACTICE` arrays near the top of
the `<script>` block. Commit and push; GitHub Pages redeploys in a minute or so.
